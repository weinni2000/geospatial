Extra drawing options for the vector layers of geoengine views.

- **Color for 0 / Empty Values**: on proportional symbol and colored
  range layers, features whose attribute value is 0 or empty are drawn
  in their own color (e.g. red), so places without a value stand out
  from places with a small value. The legend gets a line for this color.
- **Colored Proportional Symbols** (opt-in): the symbols of a
  proportional symbol layer are also colored by their value, with the
  classification, end color and number of classes of the layer, like a
  colored range layer.

Configuration
=============

Open a vector layer (*Settings > Technical > Geoengine > Vector Layers*,
or the pencil next to the layer on the map) and set **Color for 0 /
Empty Values**. The field is shown for the representation modes
*Proportional Symbol* and *Colored range/Chroma.js*; leave it empty to
draw such features like any other value.

On a *Proportional Symbol* layer, check **Colored Proportional Symbols**
to color the symbols by their value; then set the classification mode,
the end color and the number of classes as for a colored range layer.
