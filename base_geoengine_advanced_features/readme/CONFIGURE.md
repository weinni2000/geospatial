Open a vector layer (*Settings > Technical > Geoengine > Vector Layers*, or the
pencil next to the layer on the map) and set **Color for 0 / Empty Values**. The field
is shown for the representation modes *Proportional Symbol* and *Colored
range/Chroma.js*; leave it empty to draw such features like any other value.

On a *Proportional Symbol* layer, check **Colored Proportional Symbols** to
color the symbols by their value; then set the classification mode, the end
color and the number of classes as for a colored range layer.
