Extra drawing options for the vector layers of geoengine views.

- **Color for 0 / Empty Values**: on proportional symbol and colored range layers,
  features whose attribute value is 0 or empty are drawn in their own color
  (e.g. red), so places without a value stand out from places with a small
  value. The legend gets a line for this color.
- **Colored Proportional Symbols** (opt-in): the symbols of a proportional
  symbol layer are also colored by their value, with the classification, end
  color and number of classes of the layer, like a colored range layer.
